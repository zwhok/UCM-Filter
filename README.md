# UCM-Filter

**UCM-Filter: A Clustered Noise Filtering Algorithm for Space-Borne Photogrammetric Point Clouds Based on Unconstrained Cloth Simulation and Morphological Detection**

UCM-Filter is a point-cloud denoising method designed for removing clustered subsurface noise from space-borne photogrammetric point clouds.

This repository serves as the project page for UCM-Filter.

The source code is currently being organized and will be considered for release after final confirmation by the co-authors.

More information will be updated after publication.
